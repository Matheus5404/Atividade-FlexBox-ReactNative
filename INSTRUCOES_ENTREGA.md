# Entrega da atividade FlexBox no Teams

## Repositório

https://github.com/Matheus5404/Atividade-FlexBox-ReactNative

O enunciado do professor pede a implementação da tela de perfil e a entrega do aplicativo em um repositório GitHub. Este repositório contém o código-fonte.

## Entregando no Teams

1. Abra a tarefa **Tarefa FlexBox**.
2. Selecione **Anexar** e adicione o link do repositório (ou insira o link conforme a opção disponível).
3. Clique em **Entregar** antes do prazo estipulado pelo professor.

## Teste recomendado

Se tiver Node.js 22.13+ instalado:

- `npm install`
- `npm run web`

Confira se o avatar, nome, descrição e os 3 indicadores aparecem e se o botão alterna entre **Seguir** e **Seguindo**.

**Importante:** publicar o código no GitHub não comprova que o aplicativo foi executado. Ainda é recomendado realizar um teste real no navegador ou celular.
